## Design Context

### Product surface
The product is `mobile/` : a React + Vite PWA, installed to a phone home screen and
opened in the field. The Streamlit app at the repo root is the earlier proof of
concept and no longer drives design decisions ; anything in this file that reads
like Streamlit guidance is stale by definition. The design system lives in
`mobile/src/theme.css` and is documented in the README ("Trois polices, trois
roles", "Echelles typographique et d'espacement", "Une seule couleur qui appelle").

### Users
A single user (the app's author), an astrophotography hobbyist shooting with a
Seestar S50. Two distinct moments of use, and they pull in opposite directions :

- **Indoors, before leaving** : "is tonight worth it, and what do I point at." Read
  on a phone or laptop, warm, unhurried, full attention.
- **Outdoors, during the session** : the journal gets filled live, in the dark, in
  the cold, often with gloves, with a dark-adapted eye that takes twenty minutes to
  recover from a bright screen. This is the demanding case, and the one that wins
  when the two conflict.

Read back months later, too : the journal is an observation notebook, not a log
file. "M31, 22h40, ca bavait" has to still mean something in six months, which is
why each note carries the conditions that were forecast at the hour it was written.

### Brand personality
NuitClaire. Quiet, precise, glanceable : an instrument panel, not a marketing page.
Three words : functional, calm, trustworthy. Every visual element should make a
one-person go/no-go decision faster, or it does not belong.

### Aesthetic direction
Card-based, dense, French UI throughout, 24h times only. Three themes, all three
first-class :

- `light` and `dark` : ordinary use.
- `night` : red monochrome on true black, for preserving dark adaptation. Not a
  gimmick and not an afterthought. It is the field mode, and it constrains
  everything else : **anything that relies on hue to carry meaning, on hairline
  weights, or on high stroke modulation breaks here**, because the whole palette
  collapses to one red at low luminance. Design for night first and the other two
  follow.

Type, in `--font-display` / `--font-text` / `--font-num`. No component names a
family ; it names the nature of what it shows.

- **Familjen Grotesk** : screen titles and section eyebrows. The only place the
  display face speaks.
- **Atkinson Hyperlegible Next** : all running text, labels, buttons, chips.
- **Atkinson Hyperlegible Mono** : figures, times, angles, object designations.
  Slashed zero, so `NGC 0891` cannot be read `NGC O891`. Fixed advance so columns
  of times line up.

Self-hosted in `mobile/public/fonts/` and precached by the service worker. Do not
add a web font from a CDN : cross-origin requests are not intercepted by the worker
and silently fail offline, which is the case the whole PWA exists for.

Scales, in `--text-*` (5 steps, ratio ~1.27) and `--space-*` (4px step). A size or a
gap that is not on the scale has no reason to exist. Night mode raises the whole
`--text-*` scale by about two pixels in one place, rather than overriding sizes
class by class.

Touch targets have a 44px floor everywhere. Where the visible control must stay
small, grow the hit area with positive padding and negative margin so nothing moves.

### Design principles
1. **Numbers first.** The score, the window, the altitude, the moon separation are
   what the eye should catch ; the words that qualify them recede. A target row
   leads with its time slot, not with its name.
2. **One color that calls.** The magenta accent means "this is where you act"
   (primary button, active filter, current tab, link). The quality ramp
   `--good`/`--mid`/`--bad` means "this is what the measurement is worth". Nothing
   else gets a color. The ramp sits at one lightness, with chroma capped at 87% of
   the accent's, so it never competes. Adding a second accent hue, or borrowing a
   ramp color for a binary flag, is the failure mode this rule exists to prevent.
3. **Nothing is decorative-only.** Every color, badge and highlight encodes real
   data. No ambient gradients, no sparkline-as-ornament, no icon added for visual
   interest.
4. **Nothing is fabricated.** The app shows what the user entered or what it
   genuinely knows. When a value is missing it says so ; it never invents a
   plausible temperature or a placeholder reading. This is a data rule before it is
   a design rule (cf. `sessions.py`), and it decides empty states : show the gap,
   name it, do not fill it.
5. **Monospace is for what is measured.** Not for labels, not for section titles,
   not for chips, not as shorthand for a technical mood. The `.nc-num` class is
   named after the role for exactly this reason.
6. **Consistency over novelty.** New components read as the same system as the
   existing cards, not as a competing style.
